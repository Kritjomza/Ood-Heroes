# Asset Consistency Checklist

- [ ] Prompt has exactly one owner linked from an index.
- [ ] Intake filename is unique, lowercase ASCII, and identifies one source.
- [ ] Approved master is supplied as identity reference when available.
- [ ] Silhouette, palette, materials, face, costume/body features, signature item, #2b1a14 outline, upper-left light, camera, and scale match the master.
- [ ] Asset remains readable at 48 CSS pixels.
- [ ] Transparent assets have clean alpha and consistent margins.
- [ ] Hero gameplay sources share baseline/contact point and order idle A, idle B, move-left A, move-left B.
- [ ] Hero right movement mirrors the left-move art; neutral idle remains unmirrored; vertical movement preserves the last horizontal facing.
- [ ] Each monster has one left-facing static source; right-facing display is a runtime mirror.
- [ ] VFX frames map one-to-one to documented atlas positions.
- [ ] Google Flow never generates an assembled atlas.
- [ ] Pending assets use provisional IDs and contain no production path, dimensions, anchor, or atlas assumption.
- [ ] No removed hero animation ID or prompt remains.
- [ ] Active totals validate as 75 / 39 / 17 / 19 and source counts as 24 / 5 / 40 / 69.
